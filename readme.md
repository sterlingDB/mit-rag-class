## Install

From the repository root:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r capstone_final_v3/requirements.txt
```

Required pip packages (listed in `requirements.txt`):

- `python-dotenv`
- `langchain-openai`
- `langchain-core`
- `langchain_chroma`
- `rank_bm25`
- `networkx`

## Run

```sh
cd capstone_final_v3
python capstone.py
```
